============================================================
 JAFFA - Installation Requirements & Setup Commands
============================================================

This is a Node.js/TypeScript project. Dependencies are managed
via npm (not pip). This file lists everything needed to run
the project.

============================================================
 PREREQUISITES (install manually)
============================================================

1. Node.js v18+ (v20+ recommended for Next.js 16)
   Download: https://nodejs.org/
   npm comes bundled with Node.js.

2. PostgreSQL (for production database)
   Download: https://www.postgresql.org/download/
   Note: SQLite is used for local dev (no install needed).

============================================================
 INSTALLATION COMMANDS
============================================================

# Step 1: Install root dependencies (from jaffa/ directory)
npm install

# Step 2: Install backend dependencies
cd backend
npm install
cd ..

# Step 3: Install frontend dependencies
cd frontend
npm install
cd ..

# Step 4: Set up environment variables
cp .env.example .env
# Then edit .env with your values (see ENV VARIABLES section below)

# Step 5: Sync database schema
npm run db:sync

# Step 6: Seed initial data (optional)
npm run seed

============================================================
 RUNNING THE PROJECT
============================================================

# Start backend (from jaffa/ root):
npm run dev

# Start frontend (from jaffa/frontend/):
cd frontend
npm run dev

# Start both at once (from jaffa/backend/):
cd backend
npm run dev:all
